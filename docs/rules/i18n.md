# User-facing text

- Every user-facing string goes through a translation key, never a literal in a template or component.
- Each key is declared in `TRANSLATION_KEYS` (`@shadergrove/shared/i18n`) and has a non-empty value in both `i18n/en.json` and `i18n/fr.json`.
- `pnpm check:i18n` fails on missing, empty, duplicate or extra keys and when a locale's placeholders differ from English. Review still has to catch hard-coded strings the check cannot see.
