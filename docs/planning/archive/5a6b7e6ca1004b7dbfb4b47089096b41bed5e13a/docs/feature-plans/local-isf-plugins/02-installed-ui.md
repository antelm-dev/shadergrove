# Worker 02 — Installation durable et onglet Installed

Lis le README du coordinateur et les types/appels remis par 01. Mission : permettre d'installer, revoir, activer, utiliser et retirer un package local dans **Plugins / Installed** sur web et desktop, avec reprise hors ligne après redémarrage. L'UI est entièrement rendue par l'hôte à partir du manifeste. Utilise une fixture simple pour le parcours ; ne code pas le convertisseur ISF.

**Lancement.** Attends l'acceptation/intégration de 01 **et** celle du jalon d'effets sur `develop`. Le coordinateur donne le SHA exact `<launch_sha_02>` de la branche d'intégration contenant les deux. Crée `codex/plugin-isf-02` dans un worktree sibling isolé `shader-studio-plugin-isf-02`, puis vérifie le statut propre. Livraison `integration-only`, base `integration-tip`. 03 démarre du même SHA, sur d'autres fichiers.

**Propriété principale.** Nouveau service `apps/web/src/app/plugins/plugin-installations.ts` avec specs, nouvelle page `apps/web/src/app/plugins/plugins-page.ts` avec specs, `apps/web/src/app/app.routes.ts` et l'entrée Plugins de `app.html`/`app.ts`. Pour desktop, un module `apps/desktop/main/src/ipc/plugins.ipc.ts` avec son raccord étroit dans `main.ts` et le bridge généré. Ce nombre de fichiers est nécessaire au même parcours web/desktop ; garde tout autre changement hors scope et coordonne les contrats avec 03.

**Travail.** Le sélecteur local accepte `.sgplugin.json`, passe ses octets au validateur de 01, affiche identité, éditeur, licence, version, contributions, limites et statut de signature locale avant une activation explicite. Persisté web : IndexedDB, séparé par profil anonyme/compte, sans réutilisation des octets du compte précédent. Persisté desktop : fichiers de l'app sous `userData`, avec IPC borné ; le renderer et le Worker ne fournissent aucun chemin, et aucune autre fenêtre ne peut invoquer un stockage hors du profil. Relis, revalide et désactive automatiquement une installation corrompue ou devenue incompatible. Un retrait enlève le package installé, sans réécrire les shaders qui ont copié ses effets.

Installed liste les contributions et construit le formulaire depuis les MIME/paramètres simples du manifeste. Pour `importer`/`exporter`, choisir le fichier/les paramètres puis appeler le host de 01 ; aucune écriture avant validation du résultat. Pour `effect`, l'hôte ajoute une copie de définition `custom` à la chaîne existante et garde la provenance facultative. Prévois les points de raccord génériques que le coordinateur reliera au package ISF de 03. Une mise à jour locale se fait par un nouveau fichier, avec version visible dans Installed ; le service de catalogue est différé. Respecte navigation clavier, i18n et route `/plugins` sur web et desktop.

**Vérification.** Specs installation/UI et IPC ciblées ; `pnpm --filter @shadergrove/web typecheck`, `pnpm --filter @shadergrove/desktop typecheck`, `pnpm check:i18n`. Couvre AC-INSTALLED et AC-PACKAGE : installation invalide refusée, partitionnement de compte, reprise hors ligne, retrait, deux instances d'un effet déclaratif après suppression du package. Relis le diff complet, fais 1–3 commits et rapporte base/HEAD, commits, chemins, checks, risques et les chemins E2E à finir en intégration. Aucun push ni PR.
